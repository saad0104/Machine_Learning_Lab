\section{Method}
The single-layer perceptron uses the hard-limit activation and updates its
weights after each misclassified example. Features were standardized using the
training partition. A separate XOR demonstration illustrates the limits of a
linear decision boundary.

\section{Results}
The model achieved 98.5\% test accuracy and F1 0.984; the confusion matrix had
two false positives and two false negatives. It did not converge to zero
training errors within 100 epochs. As expected, a single perceptron also could
not correctly classify XOR, a non-linearly separable problem.
