\section{Method}
A one-hidden-layer network was trained from scratch with backpropagation,
sigmoid hidden units, and a softmax output. Pixel values were scaled to $[0,1]$.
The hidden-layer size was selected on a validation subset; the separate test
split was used once for final scoring.

\section{Results}
The validation-selected network had 128 hidden units. It reached 97.8\% test
accuracy and macro F1 0.978, with 25 errors among 1,124 test images. The most
frequent confusion was digit 5 classified as 9 (three cases).
