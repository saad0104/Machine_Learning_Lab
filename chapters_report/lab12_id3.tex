\section{Method}
ID3 selects each split by information gain, using entropy to measure class
impurity. The experiment reports the root gains, evaluates a full tree, and
compares test accuracy under several maximum-depth limits.

\section{Results}
Safety had the greatest root information gain (0.278 bits), followed by persons
(0.224 bits). The full tree had 85 decision nodes and depth 6; it achieved
92.3\% test accuracy and weighted F1 0.925. Its perfect training accuracy
versus lower test accuracy indicates some overfitting; a depth-5 tree reached
the same test accuracy with fewer leaves.
